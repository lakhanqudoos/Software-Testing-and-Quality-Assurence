# Software Testing and Quality Assurance

## Lab tasks

Complete the following labs in order. Use a separate test report or
short README section for each lab that records the exercise steps,
commands, observations, and results.

### Lab 1: Test planning

- Identify the functional and non-functional requirements for a sample
  application.
- Create a test plan that includes scope, entry and exit criteria,
  responsibilities, resources, risks, and a test schedule.
- Define representative test cases and their expected results.

### Lab 2: Test-case design

- Design equivalence-partition and boundary-value test cases.
- Add decision-table and state-transition test cases for a defined
  feature.
- Review the cases for completeness, traceability, and repeatability.

### Lab 3: Unit testing

- Choose a small application or module.
- Write unit tests for normal, boundary, and error conditions.
- Run the tests and report code coverage and untested branches.

### Lab 4: Integration and API testing

- Build or select a system with at least two interacting components.
- Verify component interactions and one or more API workflows.
- Record request, response, expected behavior, and actual behavior.

### Lab 5: System and acceptance testing

- Perform black-box tests against the documented requirements.
- Record defects with reproduction steps, severity, priority, and evidence.
- Execute acceptance criteria and document pass or fail status.

### Lab 6: Quality metrics and reporting

- Collect test execution, defect, and coverage metrics.
- Analyze trends and identify remaining quality risks.
- Produce a final report with conclusions and recommendations.
